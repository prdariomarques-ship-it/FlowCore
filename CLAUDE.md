# FlowCore — Project Instructions

repository, read **`FLOWCORE_CONSTITUTION.md`** in this same directory. It defines
FlowCore's mission, architecture principles, design system, and agent
responsibilities (Claude Code = architecture/engineering, Jules = implementation/UI).

silently complying or silently overriding it.
